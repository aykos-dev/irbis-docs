# Feature media

One folder per feature: `design/media/<slug>/` with `MEDIA.md` (the list `/feature` writes in step 1) and the files the
owner drops in — badge art, league emblems, mascot animations or videos, illustrations.
Preferred formats: SVG for flat art and icons, PNG @3x for raster art, Lottie JSON or MP4 (H.264, ≤ 1080p) for
animation/video — confirmed per feature. Files are copied into the app's assets by the feature; this folder keeps the
originals.
